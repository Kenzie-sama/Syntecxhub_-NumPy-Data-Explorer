# NumPy Data Explorer

A beginner-friendly Python project designed to explore the fundamental features of NumPy through a simple student marks dataset.

The project demonstrates how NumPy can be used for numerical data manipulation, statistical analysis, array transformation, file operations, and efficient computation.

---

## 📌 Project Overview

NumPy is one of the fundamental libraries used in Python for numerical computing and forms an important foundation for Data Science, Machine Learning, and scientific computing.

In this project, a student marks dataset is represented using NumPy arrays and analyzed using different NumPy operations.

The project covers:

- Array creation
- Array properties
- Indexing and slicing
- Mathematical operations
- Statistical operations
- Axis-wise calculations
- Reshaping
- Broadcasting
- Saving and loading NumPy arrays
- Performance comparison between NumPy arrays and Python lists

---

## 🎯 Objectives

The main objectives of this project are to:

1. Understand how NumPy arrays work.
2. Practice indexing and slicing multidimensional arrays.
3. Perform mathematical operations efficiently.
4. Calculate statistical values using NumPy.
5. Understand the concept of axes.
6. Practice reshaping arrays.
7. Understand NumPy broadcasting.
8. Learn how to save and load NumPy arrays.
9. Compare NumPy performance with standard Python lists.

---
